# 11. Glossário

| Termo | Significado |
| --- | --- |
| Administrador | Perfil de nível 5. Administra o sistema do próprio gabinete |
| Alcance | O conjunto de registros que um usuário pode ver. O Assessor Externo só alcança o que é seu |
| Andamento (publicação de andamento) | Texto escrito deliberadamente para o cidadão, publicado na página pública. Não é comentário interno |
| Aviso | Comunicação interna a um usuário (sino). Não tem conteúdo próprio, aponta para um registro |
| CEAP | Cota para o Exercício da Atividade Parlamentar, da Câmara dos Deputados |
| Competência | Mês ao qual uma despesa da CEAP é atribuída |
| Comentário interno | Texto de uso interno da equipe, nunca público |
| Conjunto publicável | A lista fechada do que a área pública pode mostrar |
| Consentimento | Autorização do cidadão para receber e-mail de andamento |
| Decisor | Componente único que decide se uma operação é permitida |
| Demanda | Solicitação de um cidadão ao gabinete. No vocabulário público, "solicitação" |
| Destinação | Parcela de uma emenda dirigida a um beneficiário |
| Despesa | Lançamento da CEAP, com comprovante |
| Etapa | Unidade de um fluxo. Todo status deriva do papel da etapa |
| Execução | Valor efetivamente executado de uma destinação |
| Habilitação | Concessão de uma área a um usuário: AT, AG, LG, FI |
| Link de acompanhamento | Endereço público, com segredo aleatório, que mostra uma demanda ao cidadão |
| Movimentação | Registro de cada transição de etapa |
| Nível | Posição hierárquica do perfil (1 a 5) |
| Outbox | Padrão em que o evento a notificar é gravado na mesma transação do ato e enviado depois pelo worker |
| Papel (de etapa) | Entrada, Intermediária, Conclusão ou Arquivamento |
| Pessoa | O cidadão atendido, cadastrado por telefone |
| Parlamentar | Perfil da Deputada: vê tudo, opera e acompanha, mas na CEAP só consulta e não administra o sistema. Um único usuário ativo, conta pessoal |
| Perfil | Parlamentar, Administrador, Chefe de Gabinete, Supervisor, Assessor Interno ou Assessor Externo |
| Política de publicação | Declaração versionada do que o cidadão pode ver |
| Protocolo | Identificador de 12 caracteres de uma demanda, imutável |
| Restrito | Nível de visibilidade de compromisso que não aparece nem como horário ocupado |
| Saldo | Valor derivado das movimentações; nunca armazenado |
| Trilha | Registro imutável de tudo que acontece no sistema |
| Vínculo | Relação que liga tarefa, comentário, documento, compromisso ou movimentação ao registro de origem |
| Vigência | Intervalo de datas em que um parâmetro vale |

## Vocabulário a evitar na área pública

| Não usar | Usar |
| --- | --- |
| Demanda | Solicitação |
| Protocolar, tramitar | Registrar, andamento |
| Deferido, indeferido | Concluída, sem solução |
| Etapa, fluxo, status | Situação, andamento |
| Responsável, autor | nada (não é publicável) |
| Prazo, SLA | nada (previsão não é compromisso) |
